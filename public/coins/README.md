# Cryptocurrency logos

Unmodified color SVG assets for BTC, ETH, and USDC from
[Cryptocurrency Icons](https://github.com/spothq/cryptocurrency-icons/tree/master/svg/color).
The project's CC0 license is included in LICENSE.md.

SOL uses the official gradient logomark from [Solana's brand assets](https://solana.com/branding),
downloaded from https://solana.com/src/img/branding/solanaLogoMark.svg.
The Solana asset is subject to its own brand guidelines, not the CC0 license above.

These files are served locally so logos do not depend on the live market API or an image CDN.
